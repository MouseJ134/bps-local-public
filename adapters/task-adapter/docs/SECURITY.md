# 安全与发布边界

此适配器是面向本机受信任用户的前置 HTTP 代理，不是多租户服务或任意 URL 代理。它处理的请求和响应可能包含敏感内容，运行主机及本地上游服务仍需受信任。

## 网络与认证

- 服务仅绑定 `127.0.0.1`，并检查实际 TCP 对端、Host、Origin 和跨站请求标记。
- 上游目标在启动时显式配置，不能由单次请求选择；禁止跟随上游重定向。
- 客户端和上游使用分离的凭据文件。客户端 Bearer 值与本地允许凭据比较；上游只使用专门配置的上游密钥。
- 客户端 Authorization、Cookie、账号/组织身份头及常见替代认证头不会原样转发上游。
- 不使用系统代理环境、上游 Cookie jar 或自动解压。WebSocket 升级在完成认证后返回 426，调用方需支持 HTTP/SSE。

这些检查不能阻止已控制本机用户账户、凭据文件或上游进程的攻击者。请使用操作系统权限保护密钥文件；不要将服务暴露到公网。

## 请求与结果

策略默认关闭，启用后仍按明确范围追加提示。遇到未知声明、冲突、预算超限或完整性保护时跳过提醒，保留原始请求体；HTTP 认证与转发规则仍会应用。

适配器不执行客户端工具，不添加不存在的执行器，不放宽 schema，不改变用户授权，不伪造工具调用/结果配对，不进行自动重放。任务 profile 是固定流程提示，不是权限或系统策略。

HTTP 响应正文不作内容改写。SSE 开始后发生传输错误时关闭连接，客户端仍能观察失败；不会在半截流中追加伪造的成功结果。

## 日志和隐私

仅保留明确选择的结构化元数据，例如固定路由、状态、字节数、耗时、目录数量与哈希、固定 profile 和错误分类。未知路径使用固定占位值。默认不保存请求/响应正文、查询字符串、Session-Id、真实工具参数、聊天历史或凭据。

错误观察只保留固定允许的工具名称及有界数值位置。虽然目录哈希不直接包含名称或 schema，它可能用于关联相同工具配置；仍应将运行日志视为内部诊断资料。默认不输出未知工具名，避免错误正文把私有标识夹带进日志。

## 可发布内容

本子目录只应包含通用 Python 源码、合成测试、默认关闭的策略、使用占位值的启用示例和文档。发布包不得包含：

- 真实凭据、OAuth 文件、请求录制、聊天历史、私人 session/message ID。
- 本机生产配置、备份、诊断原文、环境目录或个人绝对路径。
- CPA-BPS 的闭源插件、发行二进制，或对这些组件的源码/许可推断。

测试使用本地模拟 HTTP/SSE 上游与合成数据，不要求真实 BPS 凭据。CI 构建和测试成功不等于已完成真实上游验收，也不自动部署本机服务。
