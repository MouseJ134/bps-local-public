# 更新记录

## 0.6.0-dev.2 — 2026-11-17

### 参数契约对齐

- 新增默认关闭的策略 v3 参数提醒，按 session 显式选择当前目录中的 function 工具；兼容 v1/v2。
- 提示当前完整验证 schema 及摘要，独立于旧目录提醒，支持幂等和 schema 变化。参数不会被自动改名，校验不会被放宽。
- 保留请求范围、完整性头和有界 gzip/zstd 检查；修复目录/参数提醒串联后的编码头处理。
- 增加合成参数契约与本地 HTTP 集成回归，涵盖错误字段、缺失/冲突、预算、旧提醒、类型和压缩链。

### 流式观察与打包

- 修复 SSE CRLF 被网络分片拆开时的事件预算计数，覆盖逐字节与边界分片回归；原响应字节不改写。
- 打包清单加入参数模块、测试与本文；源码包继续使用确定性文件清单和 SHA-256。

### 证据与范围

此版本将本地定位得到的参数名不匹配修复提炼为通用配置。公开测试与 CI 使用合成请求及 localhost 模拟上游；不包含真实会话、附件、凭据、生产配置或精确聊天历史修补规则。此前特定环境的原窗口验收不能替代这个可移植包在其他环境中的验证。

这是独立任务适配器开发版本，不是 CPA-BPS 插件二进制升级。目录外工具、missing_tool_call 和 schema/resource 是不同故障类别；本版本不承诺自动修复所有类别，不伪造调用配对或成功结果。
